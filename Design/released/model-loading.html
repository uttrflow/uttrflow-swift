Speech model loading at app start

After a Mac restart the speech model has to be read into memory before anyone can dictate. Everything else in the app works during that time (History, Dictionary, Clipboard…). Only dictation waits. Below: how it looks today, what the redesign currently shows, and five ways to make the wait feel shorter and clearer. Each option shows the Home hero and the floating button.
